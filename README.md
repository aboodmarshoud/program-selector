# دليل اختيار البرامج

تطبيق تفاعلي يساعد طلاب البرامج الإلكترونية على اختيار البرنامج الأنسب لهم، بدل التسجيل في كل برنامج جديد دون وضوح في الحاجة أو المرحلة أو القدرة على الالتزام.

الفكرة الأساسية للمشروع: أن يجيب المستخدم عن مجموعة أسئلة بسيطة حول عمره، وهدفه، وطريقة التعلم التي تناسبه، وتجربته السابقة مع البرامج، ثم تعرض له الأداة البرنامج الأقرب له مع بدائل قريبة وتنبيهات قبل التسجيل.

## لماذا هذا المشروع؟

كثير من الطلاب يتحمسون عند فتح أي برنامج جديد، فيسجلون دون تمييز بين طبيعة البرامج. بعض البرامج للتأسيس الشرعي، وبعضها للبناء الفكري، وبعضها للناشئة، وبعضها للتخصص، وبعضها للمحضن التربوي أو العمل الإصلاحي.

هذا المشروع يحاول أن يقلل التشتت، وأن يساعد الطالب على أن يسأل نفسه:

- ما احتياجي الحقيقي الآن؟
- ما البرنامج المناسب لعمري ومرحلتي؟
- هل أحتاج بناءً علميًا، أم بيئة تربوية، أم تثبيتًا إيمانيًا، أم تخصصًا؟
- هل الأفضل أن أبدأ برنامجًا جديدًا، أم أستمر في البرنامج الذي أنا فيه؟
- هل البرنامج الذي أفكر فيه يناسب وقتي وقدرتي على الالتزام؟

## ماذا يقدم التطبيق؟

- اختبار تفاعلي لاختيار البرنامج الأنسب.
- أسئلة تراعي العمر، الهدف، الوقت المتاح، وطبيعة التعلم المناسبة.
- مراعاة حالة الطالب: لم يدخل برامج من قبل، طالب حالي، متخرج أو قريب من التخرج.
- توصية رئيسية مع بدائل قريبة ونِسب مناسبة.
- صفحة تفصيلية لكل برنامج، تشمل الأهداف، الفئة المناسبة، المدة، والتنبيهات قبل التسجيل.
- مقارنة عامة بين البرامج والمسارات.
- حقول قابلة للتحديث لاحقًا لروابط المواقع، قنوات تلجرام، وحالة التسجيل.

## البرامج المشمولة

- برنامج عالِم
- البناء المنهجي - المسار الأساسي
- البناء المنهجي - المسار الميسّر
- البناء الفكري
- أكاديمية الجيل الصاعد بمساراتها:
  - بذور
  - جذور
  - غراس
  - إشراق
  - إثمار
- أكاديمية الحديث الإلكترونية
- برد اليقين
- مدرسة خديجة
- خارطة الثغور

## آلية عامة للاستخدام

يدخل المستخدم إلى الصفحة الرئيسية، ثم يختار بدء الاختبار. بعد الإجابة عن الأسئلة، تظهر له نتيجة مخصصة، قد تكون:

- ترشيح برنامج جديد مناسب له.
- نصيحة بالتركيز في برنامجه الحالي إن كان مناسبًا.
- تنبيه للاستدراك بدل الهروب إلى برنامج جديد.
- اقتراح خطوة لاحقة إذا كان قد تخرج من برنامج سابق.

## تشغيل المشروع محليًا
### المتطلبات

- Node.js
- npm

### خطوات التشغيل

```bash
npm install
npm run dev
```

بعد التشغيل افتح الرابط الذي يظهر في الطرفية، وغالبًا يكون:

```bash
http://localhost:3000
```

### أوامر مفيدة

```bash
npm run dev       # تشغيل بيئة التطوير
npm run build     # بناء نسخة الإنتاج
npm run preview   # معاينة نسخة الإنتاج محليًا
npm run lint      # فحص TypeScript دون إخراج ملفات
```

## ملاحظات تطويرية

- بيانات البرامج موجودة داخل الكود وقابلة للتحويل لاحقًا إلى ملف JSON أو قاعدة بيانات.
- حقول روابط الموقع الرسمي، قنوات تلجرام، وحالة التسجيل موجودة ليتم تحديثها لاحقًا.
- يمكن تطوير الخوارزمية بإضافة حالات اختبار لكل مسار للتأكد من دقة الترشيح.
- يمكن لاحقًا إضافة لوحة إدارة بسيطة لتعديل بيانات البرامج دون تعديل الكود.

## تنبيه

هذا المشروع مبادرة مساعدة للطلاب على الاختيار، وليس بديلًا عن قراءة الشروط الرسمية لكل برنامج عند فتح التسجيل. ينبغي دائمًا الرجوع إلى الإعلان الرسمي الأحدث قبل التسجيل.
